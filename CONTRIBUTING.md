# Contributing

Thanks for taking the time to contribute.

> **Found a security vulnerability?** Don't use an issue or PR for that —
> see [SECURITY.md](SECURITY.md) and report it privately instead.

- **Bugs and feature requests**: open an issue on the relevant repo. Include
  enough detail to reproduce (steps, versions, environment) for a bug, or the
  problem you're trying to solve for a feature request.
- **Pull requests**: keep them focused on one change. Add or update tests
  where the project has them, and make sure the existing suite passes before
  opening the PR.
- **Questions**: open a discussion or issue rather than emailing us directly —
  it helps other people who hit the same thing. (This doesn't apply to
  security reports — those go through [SECURITY.md](SECURITY.md), privately.)

Individual repos may have their own `CONTRIBUTING.md` with project-specific
setup steps; this file is the fallback for repos that don't.
